# Requests

PACE's own Knowledge Intake: every permanent observation from the
ROOT_AUTHORITY, logged the moment it is stated, before being acted on.
Core fields (WHO, DATE, RAW_TEXT) are immutable; STATUS and PROMOTED_TO
advance as each request is approved and promoted into a policy, protocol,
standard, or rule of behaviour for AIs.

See ../protocols/LEARNING_PROTOCOL_0.1.0.pdl for the full
intake -> scope -> promotion cycle.
