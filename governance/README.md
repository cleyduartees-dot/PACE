# Governance

The abstract governance framework of PACE itself: a highest-authority role exists, decisions must be traceable, history is never overwritten, versioning is permanent.

This folder deliberately names no organization and no person *in its abstract protocol*. Who actually holds those roles, and any organization-specific policy, belongs to that organization's own governance instance — never hardcoded there.

PACE's own Mission and Vision are a different kind of artifact: assertions about PACE's own identity and purpose (not universal rules), so — same as any Mission/Vision assertion in the Ontology — they do carry an `OWNER` who approved them.
