# Standards

Quality bars and conventions for what PACE creates or manages: the
project-starter standard, the generated-project isolation standard, the
project-management standard, the documentation standard.

- [`PROJECT_MANAGEMENT_STANDARD_0.1.0.pdl`](./PROJECT_MANAGEMENT_STANDARD_0.1.0.pdl) — the ClickUp shape every governed project takes: a folder per project, the required lists, and a Roadmap seeded from the project's own `.pace/` roadmap (DRAFT).
- [`DOCUMENTATION_STANDARD_0.1.0.pdl`](./DOCUMENTATION_STANDARD_0.1.0.pdl) — where an AI puts documentation and presentations it produces: ClickUp Docs inside the project's folder, opt-in at the ROOT_AUTHORITY's choice (DRAFT).

Project-starter and isolation standards not written yet.
