# Lanzadores de PACE (doble clic, sin terminal)

Estos archivos abren el **menú guiado de PACE** con un doble clic, para que
cualquiera lo use sin escribir comandos.

- **Windows:** `PACE.bat` — doble clic. Se abre el menú; eliges un número.
- **macOS:** `pace.command` — doble clic (la primera vez quizá tengas que
  permitirlo en Ajustes → Privacidad y seguridad).
- **Linux:** `pace.sh` — `bash pace.sh` o marca como ejecutable.

Requisito actual: tener **pace-engine** instalado (`pip install pace-engine`).
La experiencia totalmente sin Python llegará con el **binario standalone**
(roadmap F5·23): entonces el lanzador no necesitará nada previo.
